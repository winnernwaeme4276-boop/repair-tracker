# Repair & Warranty Management Tracker

A fast, lightweight web application for electronics repair workshops and computer/phone technicians.

## Features
- **Workshop Queue:** Real-time intake registration and repair status management.
- **✨ Gemini AI Hardware Diagnostics:** Automated bench analysis, root cause hypotheses, multimeter test steps, and difficulty ratings powered by Google Gemini.
- **Thermal Label & Sticky Tag Printing:** Direct 58mm/80mm thermal receipt printer support.
- **Instant WhatsApp Receipts:** Pre-formatted digital intake and "Ready for Pickup" notifications with balance due and shop address.
- **Warranty Audit:** Serial number and IMEI verification calculated from actual collection dates.
- **Shop Profile:** Customizable business name, plaza address, and contact numbers.

## Tech Stack
- Frontend: HTML5, Tailwind CSS, Vanilla JavaScript
- Backend / Database: Supabase
- AI: Google Gemini API (gemini-3.8-flash / gemini-3.6-flash fallback)
- Deployment: Vercel / GitHub Pages
